# 訓練動作分類系統分析報告

> **分析日期**：2026-01-17
> **資料來源**：794 個系統預設訓練動作

---

## 📊 現行分類架構

### 主要分類維度

| 維度 | 欄位名稱 | 用途 | 目前使用狀況 |
|------|----------|------|--------------|
| **訓練類型** | `training_type` | 第一層篩選 | 3 種類型 |
| **身體部位** | `body_part` | 第二層篩選 | 9 種部位 |
| **器材類別** | `equipment_category` | 器材過濾 | 4 種類別 |
| **特定肌群** | `specific_muscle` | 細分目標肌肉 | 多樣化 |
| **追蹤模式** | `tracking_mode` | 記錄方式 | 8 種模式 |
| **階層命名** | `level1` ~ `level5` | 動作層級分類 | 部分動作使用 |

## 📈 分類統計

### 1. training_type 訓練類型分佈

| 類型 | 數量 | 佔比 |
|------|------|------|
| 阻力訓練 | ~744 | 93.7% |
| 活動度與伸展 | ~30 | 3.8% |
| 心肺適能訓練 | ~20 | 2.5% |

### 2. body_part 身體部位分佈

| 部位 | 說明 |
|------|------|
| 全身 | 複合動作（深蹲、硬舉、舉重等）|
| 胸部 | 臥推、夾胸等 |
| 背部 | 划船、引體向上等 |
| 肩部 | 推舉、飛鳥等 |
| 手 | 二頭、三頭等 |
| 腿部 | 腿推、弓步等 |
| 核心 | 棒式、捲腹等 |
| 臀部 | 臀推、蚌式等 |

### 3. equipment_category 器材類別

| 類別 | 包含器材 |
|------|----------|
| 徒手訓練 | 自身體重、TRX、戰繩等 |
| 自由重量 | 槓鈴、啞鈴、壺鈴 |
| 固定式機械 | 各種機械訓練設備 |
| 纜繩 | Cable 系列動作 |

### 4. tracking_mode 追蹤模式

| 模式 | 用途 | 適用動作 |
|------|------|----------|
| `weight_reps` | 重量 × 次數 | 大多數阻力訓練 |
| `reps_time` | 次數 × 時間 | 伸展、動態熱身 |
| `reps_only` | 僅次數 | 跳箱、波比跳 |
| `time_only` | 僅時間 | 棒式、靜態支撐 |
| `distance_time` | 距離 + 時間 | 跑步機、划船機 |
| `calories` | 卡路里 | 風扇車 |

## ⚠️ 現行問題診斷

### 問題 1：動作命名規則不一致

**現象**：
```
✅ 正確格式：「推／伏地挺身／半跪式／寬距／雙膝支撐」
❌ 不一致：「深蹲」vs「深蹲／背蹲」vs「深蹲／前蹲」
❌ 混用：「跳/箱跳」vs「跳／箱跳」（斜線符號不統一）
```

**影響**：
- 搜尋體驗不佳
- level1-5 欄位資料不完整

---

### 問題 2：「全身」分類過於籠統

**現象**：
大量動作被歸類為 `body_part: "全身"`，包括：
- 伏地挺身（主要胸部）
- 引體向上（主要背部）
- 深蹲（主要腿部）
- 舉重動作（全身）

**問題**：
- 無法按「主要訓練部位」有效篩選
- 使用者難以找到想練的動作

---

### 問題 3：equipment_category 誤標

**現象**：
```json
// 戰繩動作，但歸類為「徒手訓練」
{ "name": "戰繩/上下甩繩", "equipment_category": "徒手訓練" }

// 槓鈴舉重動作，但歸類為「徒手訓練」
{ "name": "舉重動作/上挺/Jerk", "equipment_category": "徒手訓練" }
```

**原因**：
- 可能是資料轉換時的遺漏
- 需要重新校正器材對應

---

### 問題 4：level1-5 階層命名未完整利用

**現象**：
- 部分動作有填寫（如「推 → 伏地挺身 → 半跪式」）
- 部分動作完全沒填

**價值**：
這套階層命名系統其實是很好的設計，可以支援：
- 動作進退階關聯
- 動作家族分群
- 智慧推薦

---

## 💡 改善建議

### 建議 1：建立「主要目標部位」欄位

**方案**：新增 `primary_body_part` 欄位

| 動作 | body_part | primary_body_part |
|------|-----------|-------------------|
| 槓鈴臥推 | 胸部 | 胸部 |
| 引體向上 | 全身 | **背部** |
| 深蹲 | 全身 | **腿部** |
| Power Clean | 全身 | 全身 |

**好處**：
- 保留原本的 `body_part`（完整分類）
- 新增 `primary_body_part`（使用者友善篩選）

---

### 建議 2：統一命名規則

**命名公式**：
```
[動作模式] / [主動作] / [變化型] / [器材/握法] / [姿勢]
```

**範例**：
- `推 / 臥推 / 平板 / 槓鈴 / 標準`
- `拉 / 划船 / 俯身 / 啞鈴 / 單手`
- `蹲 / 深蹲 / 背蹲 / 槓鈴 / 寬站`

---

### 建議 3：完善 level1-5 階層

**建議填寫規則**：

| 層級 | 內容 | 範例 |
|------|------|------|
| level1 | 動作模式 | 推、拉、蹲、髖鉸鏈 |
| level2 | 主動作名稱 | 臥推、划船、深蹲 |
| level3 | 變化型態 | 平板、上斜、俯身 |
| level4 | 器材/握法 | 槓鈴、啞鈴、窄握 |
| level5 | 姿勢/細節 | 雙腳、單腳、爆發 |

---

### 建議 4：新增分類維度（可選）

| 新欄位 | 說明 | 價值 |
|--------|------|------|
| `movement_pattern` | 動作模式 | 推/拉/蹲/髖鉸鏈/旋轉/攜帶 |
| `joint_action` | 關節動作 | 單關節/多關節 |
| `difficulty_level` | 難度等級 | 初階/中階/進階 |
| `is_unilateral` | 單側訓練 | true/false |
| `requires_spotter` | 需要保護 | true/false |
