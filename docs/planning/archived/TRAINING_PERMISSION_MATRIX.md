## 一、日期限制（最高優先級）

無論任何身份或類型，日期限制具有最高優先級。

| 日期 | 訓練計劃卡片 | 訓練執行頁面 |
|------|-------------|-------------|
| **過去** | ❌ 只能看（不能編輯、刪除） | ❌ 只能看（不能編輯、打勾、開始訓練） |
| **今天** | 依類型權限 | 依類型權限 |
| **未來** | 可編輯/刪除，不能打勾/開始 | 可編輯/新增/刪除，不能打勾/開始 |

## 二、學員視角 - 訓練計劃卡片

學員在訓練行事曆上看到的訓練計劃卡片。

### 權限表

| 類型 | 圖示 | 刪除計畫 | 編輯計畫 |
|------|------|---------|---------|
| **個人** | 🏃 自主訓練 | ✅ | ✅ |
| **教練安排** | 📋 教練安排 | ❌ | ✅ |
| **上課** | 📍 上課 | ❌ | ❌ |

### 說明

- **個人（自主訓練）**：學員自己創建的訓練計畫，完全控制
- **教練安排**：教練在學員的偏好時間建立的計畫，學員不能刪除
- **上課**：Session Mode 關聯的訓練計畫，學員只能在課程中查看

## 三、學員視角 - 訓練執行頁面

學員進入訓練執行頁面後的操作權限。

### 權限表

| 類型 | 新增動作 | 新增組數 | 調整重量/次數 | 刪除動作 | 減少組數 | 打勾 | 開始訓練 |
|------|---------|---------|--------------|---------|---------|------|---------|
| **個人** | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **教練安排** | ✅ | ✅ | ✅ | ❌ | ❌ | ✅ | ✅ |
| **上課** | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ |

### 說明

- **個人**：完全控制，可以任意修改訓練內容
- **教練安排**：可以增加內容（新增動作、組數、調整重量次數），但不能減少（刪除動作、減少組數）。這讓學員可以根據自身狀況調整訓練強度，但不能偷懶刪除教練指定的動作
- **上課**：只能查看，所有操作必須在 Session Mode 中由教練執行

## 四、教練視角 - 幫學員建立的計畫

教練在學員的偏好時間建立訓練計畫。

### 權限表

| 操作 | 自己創建的 | 其他教練創建的 |
|------|-----------|---------------|
| 編輯（新增/刪除動作、組數、調整重量次數） | ✅ | ❌ |
| 刪除計畫 | ✅ | ❌ |
| 開始訓練（計時） | ❌ | ❌ |
| 打勾（標記完成） | ❌ | ❌ |

### 說明

- 教練只能編輯/刪除自己創建的計畫
- 教練不能幫學員打勾或開始訓練（這是學員自己的事）
- 教練不能在過去的日期建立計畫（只能今天或未來）

## 五、教練視角 - Session Mode

教練在上課模式中的權限。

### 權限表

| 時間段 | 創建/刪除計畫 | 編輯（新增/刪除動作組數） | 打勾 | 開始訓練/計時 | 編輯筆記 |
|--------|-------------|------------------------|------|-------------|---------|
| **上課前** | ✅ | ✅ | ❌ | ❌ | ✅ |
| **上課中～+4hr** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **+4hr 後** | ❌ | ❌ | ❌ | ❌ | ✅ |

### 時間窗口定義

```
課程結束後 4 小時
    ↓
──────────────────────────────────────────────────────→ 時間軸
    │         │                    │
    │         │                    │
上課前      上課開始              課程結束
    │         │                    │
    │         ├────────────────────┤
    │         │  可打勾+計時時段    │
    │         │  (canMarkSet)      │
    │         │  (canStartTraining)│
    ├─────────┴────────────────────┴───────────────→ +4hr
    │              可編輯時段                      │
    │              (canEditPlan)                  │
    ├─────────────────────────────────────────────┤
    │              永遠可編輯筆記                   │
    │              (canEditNotes)                  │
```

### 說明

- **上課前**：教練可以預先準備訓練計畫，但還不能打勾或開始計時
- **上課中～+4hr**：教練可以開始訓練（計時）、打勾標記完成、修改計畫
- **+4hr 後**：只能編輯課程筆記（SOAP），訓練計畫已鎖定

### 學員在 Session Mode

- 只能查看課程資訊
- 只能填寫課前準備度問卷
- 不能編輯任何內容

## 六、類型判斷規則

### 訓練計劃類型判斷順序

```dart
_TrainingCategory _getTrainingCategory({
  String? appointmentId,
  String? traineeId,
  String? currentUserId,
}) {
  // 1. 有 appointmentId → 📍 上課
  if (appointmentId != null && appointmentId.isNotEmpty) {
    return _TrainingCategory.session;
  }
  
  // 2. traineeId != currentUserId → 📋 教練安排
  if (traineeId != null && 
      currentUserId != null && 
      traineeId != currentUserId) {
    return _TrainingCategory.coach;
  }
  
  // 3. 其他 → 🏃 個人
  return _TrainingCategory.self;
}
```

### 權限檢查參數

| 參數 | 說明 |
|------|------|
| `isToday` | 是否為今天 |
| `isPastDate` | 是否為過去日期 |
| `isFutureDate` | 是否為未來日期 |
| `isCoachViewingTrainee` | 教練是否在查看學員訓練 |
| `isViewingOthersCreatedPlan` | 是否在查看別人創建的計畫 |
| `isSessionPlan` | 是否為上課類型（有 appointmentId） |

## 七、相關代碼位置

### 權限檢查器

```
lib/controllers/workout_execution/workout_execution_permission_checker.dart
```

主要方法：
- `canEdit()` - 是否可以編輯（修改重量/次數）
- `canAdd()` - 是否可以新增（新增動作/組數）
- `canDelete()` - 是否可以刪除（刪除動作/減少組數/刪除計畫）
- `canToggleCompletion()` - 是否可以打勾
- `canStartTraining()` - 是否可以開始訓練

### 訓練記錄保存器

```
lib/controllers/workout_execution/workout_execution_record_saver.dart
```

⚠️ **重要**：保存時必須保留 `appointmentId`，否則「上課」類型會變成「教練安排」

### 訓練計劃卡片

```
lib/views/pages/scheduling/booking/widgets/training_plan_card.dart
```

主要方法：
- `_getTrainingCategory()` - 判斷訓練類型
- `_canDelete()` - 是否可以刪除計畫
- `_canEdit()` - 是否可以編輯計畫

### Session Mode 控制器

```
lib/controllers/session_mode_controller.dart
```

主要屬性：
- `canEditPlan` - 是否可以編輯訓練計畫
- `canMarkSet` - 是否可以打勾
- `canEditNotes` - 是否可以編輯筆記
- `isCoachMode` - 是否為教練模式

### 訓練執行控制器

```
lib/controllers/workout_execution_controller.dart
```

主要方法：
- `shouldShowTimerUI()` - 是否顯示計時 UI
  - 學員看「上課」類型 → 不顯示
  - 教練看「上課」類型 → 顯示（可計時）
